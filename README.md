## 🚀 Установка

### 1. Скопируйте файлы

Скопируйте все `.smx` файлы в папку:

addons/sourcemod/plugins/

text

### 2. Скопируйте файлы переводов

Скопируйте `is.phrases.txt` в папку:
addons/sourcemod/translations/

text

### 3. Настройте базу данных (опционально)

Добавьте в `addons/sourcemod/configs/databases.cfg`:

**Для MySQL:**
```json
"is_anticheat"
{
    "driver"            "mysql"
    "host"              "localhost"
    "database"          "is_anticheat"
    "user"              "root"
    "pass"              "your_password"
    "port"              "3306"
}
Для SQLite (без MySQL):

json
"is_anticheat_sqlite"
{
    "driver"            "sqlite"
    "database"          "is_anticheat"
}
4. Перезагрузите сервер или плагины
5. Проверьте установку
bash
is_status
is_db_status
📁 Команды
Команда	Описание	Флаг
is_status	Показать общий статус	Generic
is_config	Показать все настройки	Generic

is_banlist_status	Статус глобальных бан-листов	Generic
is_antismoke_status	Статус блокировки анти-дым	Generic
is_rcon_addip	Добавить IP в белый список RCON	Root
is_rcon_removeip	Удалить IP из белого списка RCON	Root
🛡️ Настройка иммунитета для админов
1. В файле admin_overrides.cfg:
json
"is_immunity" "o"
2. В файле admins.cfg:
json
"YourNickname"
{
    "auth"          "steam"
    "identity"      "STEAM_0:0:12345678"
    "flags"         "o"
    "immunity"      "1"
}
3. Перезагрузите админ-систему:
bash
sm_reloadadmins
